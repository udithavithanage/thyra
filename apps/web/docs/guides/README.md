# Guides

Practical tutorials and real-world scenarios to help you master Thyra and boost your productivity.

## 📖 Available Guides

### 🚀 [Basic Workflows](/guides/basic-workflows)

Learn the essential day-to-day workflows with Thyra. Perfect for getting comfortable with common tasks.

**What you'll learn:**

- Saving and opening projects
- Managing your bookmarked projects
- Using aliases and shortcuts
- Quick tips and tricks

### 🎯 [Multi-Project Management](/guides/multi-project)

Master the art of juggling multiple projects simultaneously without losing your mind.

**What you'll learn:**

- Organizing projects by client or category
- Naming conventions and best practices
- Switching contexts efficiently
- Batch operations

### 👥 [Team Collaboration](/guides/team-setup)

Set up Thyra across your team for consistent, efficient project access.

**What you'll learn:**

- Sharing configurations
- Standardizing project names
- Onboarding new team members
- Creating team workflows

### 🎨 [Editor Integration](/guides/editor-integration)

Connect Thyra with your favorite code editors and IDEs for seamless integration.

**What you'll learn:**

- Setting up VS Code integration
- Configuring JetBrains IDEs
- Using Vim/Neovim with Thyra
- Custom editor commands

### Beginners

If you've completed the [Getting Started](/getting-started/README) section, these guides will help you become proficient with Thyra's everyday features.

### Intermediate Users

Already familiar with the basics? These guides show you how to optimize your workflow and handle advanced scenarios.

Looking to implement Thyra across your organization? The team collaboration guide has you covered.

Each guide is structured as a hands-on tutorial:

1. **Introduction** - What you'll learn and why it matters
2. **Prerequisites** - What you need before starting
3. **Step-by-Step Instructions** - Practical, copy-paste examples
4. **Best Practices** - Tips from experienced users
5. **Troubleshooting** - Common issues and solutions

## 🎯 Prerequisites

Before you begin, make sure you have:

- **Node.js** v14 or higher installed ([Download here](https://nodejs.org/))
- A terminal or command prompt
- Basic command-line knowledge

Check your Node.js version:

```bash
node --version
```

---

## ⚡ Quick Installation

Can't wait to get started? Here's the fastest way:

```bash
# Install Thyra globally
npm install -g thyra

# Verify installation
thyra version

# Save your first project
thyra config my-project ~/projects/my-app

# Open it!
thyra open my-project
```

**That's it!** You're now using Thyra.

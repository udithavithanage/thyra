# Installation

Get started with Thyra in seconds.

---

## Prerequisites

Before installing Thyra, ensure you have:

- **Node.js v14 or higher** installed on your system
- **npm** (comes with Node.js)

You can check your Node.js version by running:

```bash
node --version
```

---

## Install Thyra Globally

Install Thyra globally using npm:

```bash
npm install -g thyra
```

After installation, the `thyra` command will be available system-wide from any terminal.

---

## Verify Installation

Check that Thyra was installed correctly:

```bash
thyra --version
```

Or:

```bash
thyra version
```

You should see the current version number (e.g., `v1.1.1`).

---

## Get Help

To see all available commands:

```bash
thyra --help
```
